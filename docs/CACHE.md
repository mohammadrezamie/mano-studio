## Chapter 12 cache laboratory
Added one functional 32-word cache above the existing MemoryArray (1024 x 16), 4-word blocks, 1/2/4/8 ways, LRU/FIFO, write-back or write-through with write-allocate in both modes. Valid/dirty/tag and actual data, decoded 10-bit word addresses, deterministic eviction and flush, exact word traffic and hit/miss statistics. Existing Logic Memory & bus inspector gains bilingual cache page, vector address field visualization, selected line and backing-RAM comparison, conflict example and bounded transaction trace. Configuration changes reset the entire demonstration (including RAM). No actual CPU cache integration, byte addressing, physical timing, multilevel hierarchy or coherence. Added mapping, replacement, dirty eviction, invalid input and 16 deterministic randomized oracle test configurations plus GUI route test; exact-head CI pending. 35 learning entries, all 13 chapters represented but partial. References: https://www.cs.cornell.edu/courses/cs3410/2025sp/notes/caches.html and https://notes.cs61c.org/content/caches-ii/fully-associative/ . No translator, release or installer changes.

Address A (word): offset=A mod 4; block=A // 4; set=block mod sets; tag=block // sets. Eight lines total. Invalid lines fill first, otherwise FIFO uses insertion order and LRU uses most recent access. Dirty eviction transfers the entire old four-word block to RAM before filling. Flush writes dirty data without invalidating or adding a cache access. Write-through writes one word to RAM immediately; both write policies allocate on miss. The conflict demo accesses 000,020,000,020,001,021 (hex): direct cache 0 hits; two-way cache 4 hits. Reset/configuration resets RAM, cache and counters. No timing claims.

# Procedural brand and visual assets

Single source: ui/brand.py. Original geometric M, functional circuit-inspired motif (not a schematic). SVG is generated locally; native icon sizes 16/24/32/48/64/128/256; small sizes simplify details. The same mark is painted into splash and header, with theme-aware glass and plain modes. The app's actual translation result triggers one 360ms pulse, never an artificial loading animation. Reduced motion and hidden widgets stop it. Keep the wordmark text editable and readable.

Use procedural graphics, vector symbols and real simulation traces before raster decoration. Generative artwork is allowed for optional illustrations or documentation if visibly valuable, with source/provenance and reviewed content. Generated image concepts from the conversation are not runtime assets or scientific diagrams. Do not use inaccurate generated gate drawings as instructional evidence. Never use an image as a replacement for interactive controls or actual data. Bundle approved assets locally; no streaming, arbitrary size cap, or copying incompatible licenses. Maintain clear separation between a conceptual preview and a verified screenshot.

See DESIGN_SYSTEM.md and ANIMATION_GUIDE.md. Native visual and installer acceptance remain pending.

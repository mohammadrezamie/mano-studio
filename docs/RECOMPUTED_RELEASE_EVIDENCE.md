# Recomputed release evidence (Stable child)
The previous Stable manifest verified the distribution inventory, installed payload and assets, but did not bind separate redistribution, runtime and wheel review reports. This candidate recomputes all three from the actual portable archive, exact current build interpreter and original pip report plus source constraints. Both artifact copies of the raw pip report, constraints and review reports must match; record SHA-256 of each in the manifest. Twelve focused positive/negative cases cover stale, missing, forged and contradictory evidence. The pinned candidate branch explicitly requires recomputation; legacy diagnostic builds remain non-public and report null review evidence. No runtime or translator changes, no new dependency. Recomputed evidence is not independent upstream wheel authentication, legal clearance, CVE clearance or signature verification. Existing review flags, unsigned Setup and native acceptance remain blockers. New package workflow must pass before promotion.

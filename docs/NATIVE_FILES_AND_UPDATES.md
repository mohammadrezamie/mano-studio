# Native Mano Studio files and update delivery

## Native extension
Use `.mano` for new saved RTL/Assembly input or editable combinational circuits. The UTF-8 JSON envelope has format "mano-studio", version 1, kind ("rtl", "asm", "circuit") and payload. Text payloads contain the source only; circuit payloads reuse the validated existing circuit schema. Calculated outputs are regenerated. Save stages a complete new file before replacing the old one. Opening a text project respects unsaved editor changes; opening a circuit opens Logic Lab. Files can be inserted as blocks. Legacy files still work; exported academic .asm/.rtl and CSV/SVG remain standard formats.

Windows installer optionally registers a per-user ProgID and an Open with entry for .mano, the existing app icon and quoted filename argument. Windows controls the default-app selection; users can select Mano Studio via Open with. Native association is not encryption, DRM or a claim that other programs cannot inspect the format. No bundled executable content is evaluated. The first beta installer is unchanged; association/native flow require actual Windows testing.

پسوند اختصاصی مانو استودیو .mano است. مدارها و متن‌های RTL و اسمبلی با آن ذخیره می‌شوند. فایل‌های قبلی نیز قابل استفاده‌اند. از Open with در ویندوز برنامه را برای بازکردن این پسوند انتخاب کنید. ذخیره و بازیابی وضعیت سایر آزمایشگاه‌ها به تدریج اضافه خواهد شد.

## Direct updates
Settings → Check for updates queries official GitHub releases on demand. A newer release with a single correctly named x64 installer and valid GitHub SHA-256 digest offers Download installer. Confirm and choose a new .exe path; HTTPS download runs in the existing worker thread, validates exact source URL, permitted redirect hosts, byte count and hash. No startup traffic, automatic execution or installation. Existing files are not overwritten; the target filesystem must support hard links (otherwise fails safely). The 512 MiB limit is a revisable operational safeguard, not a product-size policy. Missing digest or ambiguous assets leave official releases page as fallback. This does not certify publisher identity: signed installer and pinned trusted publisher/upgrade validation are still required before in-app execution. No actual public Release exists yet; network tests use mocked responses.

در تنظیمات ابتدا بررسی به‌روزرسانی را بزنید. اگر نسخه رسمی جدید و فایل واجد شرایط باشد، دکمه دریافت نصب‌کننده ظاهر می‌شود. فایل بررسی می‌شود ولی خودکار نصب نمی‌شود.

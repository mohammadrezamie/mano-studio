# Mano Logic Lab — development preview
The required classroom deliverable remains the independent RTL-to-assembly translator. Logic Lab is an optional offline learning workspace, not a replacement.

## Current implementation
Chapter alignment: Morris Mano, Computer System Architecture (3rd ed.), ch. 1 Digital Logic Circuits (logic gates, half/full adder); ch. 2 Digital Components (decoder, encoder, multiplexer); ch. 4 Register Transfer and Microoperations (binary adder). Reference contents: https://www.academia.edu/38425107/Computer_system_architecture_mano ; textbook text: https://studylib.net/doc/27337396/computer-system-architecture-m.-morris-mano . The demultiplexer and half subtractor are useful supplementary circuits. These original netlists are not reproductions of textbook figures.

15 selectable circuits: NOT, AND, OR, XOR, NAND, NOR, XNOR, half adder, full adder, 2-to-4 decoder, one-hot 4-to-2 encoder (explicit Valid output), 2-to-1 MUX, 1-to-2 DEMUX, half subtractor, 4-bit ripple-carry adder. The engine can construct ripple adders of width 1–8, but the UI offers 4-bit only; truth-table generation caps input count at 10.

logic_engine.py contains pure Python acyclic gate netlists. A single evaluate() supplies each internal signal and output, truth tables and diagram colors. ui/logic_lab.py provides auto-layout by logical depth, distinctive-shape gates with real pin anchors, binary input buttons, live output state, truth-table row selection and zoom/pan. Diagrams are simplified educational schematics, not optimized routing or arbitrary drag-and-drop circuit design. Signal colors show settled 0/1 values, not physical propagation delays. Persian and English labels and existing three themes; no network, no constant animations. Newly authored regression tests cover gate tables, invalid circuits, and all 512 combinations of a 4-bit adder with carry-in. Runtime and visual verification pending.

## Schematic quality requirements (owner decision)
Use original ANSI-style distinctive gate symbols, inspired by recognizable digital schematic workflows such as Proteus, not generic rectangles for elementary gates. AND/NAND D-shape, OR/NOR curved outline, XOR/XNOR extra input-side curve, NOT triangular inverter, inversion bubbles at negated outputs. Gate inputs are physical drawing anchors and match the validated netlist; NOT has exactly one input and one output; other elementary gates offer 2–4 inputs and one output, with odd/even parity explicitly documented for multi-input XOR/XNOR. Complex circuits retain their real logical ports (including the encoder's extra Valid output); do not imply IC package pin numbers or transistor-level simulation. QPainterPath symbols, orthogonal tracks, bypass lanes, fanout junction marks and settled signal values are generated offline. Routing remains preliminary: dense circuits need collision/crossing review; unrelated crossings must never imply connection. The free-wiring canvas, standard component library, clocked logic and timing diagrams remain future work.
References consulted for symbol and workflow conventions: https://open-book-project.github.io/courses/csa_course/logic-gates-and-boolean-algebra.html ; https://dmccreary.github.io/digital-electronics/chapters/03-logic-gates-digital-signals/ ; https://digsys.upc.edu/csd/units/Proteus/Proteus.html . Original vector paths, no copied proprietary assets.

## Integrated custom circuit editing — current development
The existing Logic Lab now has an embedded staged editor (ui/circuit_editor.py) and circuit_document.py. Start from any preset or Custom circuit, edit input signal names, add/remove gates, choose gate type and 1–4 pins according to gate arity, select source signals per pin, and define named outputs. Apply validates all connections and topologically sorts gates before compiling to the existing Circuit engine. Cancel leaves the applied circuit unchanged. The same schematic and truth table render the result. Undo stores up to 30 applied document snapshots. JSON v1 (.mano-logic.json) stores topology, not runtime input values or coordinates; save/open and unsaved-change guards included. Limits: 1–10 inputs, up to 96 gates, 1–16 outputs; malformed files, duplicate signals, unknown pins and combinational loops rejected. No separate simulator, no executable input. This is pin-selection editing, NOT freehand wire drawing or drag-and-drop placement; dense routing and full visual acceptance remain pending. English/Persian controls; validation messages currently English. Next: improve graphical interactions and routing, export and sequential clock/waveform within the same workspace. New tests authored, latest CI pending.

## Graphical interaction checkpoint
The same Logic Lab canvas now offers Edit on canvas mode: click a source terminal then a receiving gate/output pin to replace a connection; drag a component to a snapped position using an outline preview. Esc cancels pending gestures; overlapping drops are rejected. Edits validate and compile the same CircuitDocument, preserve input states, and participate in the existing undo history. The advanced table editor still adds/removes components. Auto layout resets saved placements. Format v2 persists optional coordinates while loading v1 files; runtime input values remain transient. Manual layouts use orthogonal obstacle-aware candidate routing, cached between input changes; blocked routes are dashed with a warning. This is not yet a general collision-free router or freehand segment editor; dense wire crossings/legibility and full visual acceptance remain pending. Export menu writes SVG of the applied schematic (without editing handles) and UTF-8 CSV truth table, using the same scene/data. New regression cases for pin validation, coordinate persistence, routing, Qt pin clicks, undo and exports. Capture script now includes full-adder simulation/edit and Computer screens in all themes/languages, in addition to translator. Latest CI pending. No network/dependencies/releases added.

## Sequential components
Existing Logic Lab now has Combinational and Sequential tabs. sequential_logic.py models ideal rising-edge D/JK/T/SR, 4-bit enabled register and enabled modulo-16 up counter. Toggle each input, change clock or pulse it, reset, view actual pins and bounded 64-event waveform. SR 11 rejects rising edge. Event order, not elapsed electrical time; no arbitrary sequential wiring or gate-delay model. No separate lab or dependency. New core and GUI tests authored, candidate CI pending.

## Net-aware notation
See SCHEMATIC_STANDARD.md. Original distinctive shapes and exact pin counts retained. Routed net identity drives filled junction dots; different-net crossings do not connect, ambiguous contact/overlap receives an outlined warning and routing guidance. Explicit multi-input parity labels and complementary flip-flop output notation. This is functional teaching notation, not device-specific IC pinout or formal certification. Latest CI pending.

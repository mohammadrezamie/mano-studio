## Chapter 8 general register organization and register stack
Added independent functional Chapter 8 teaching models in cpu_organization.py, integrated into one Computer inspector tab with two subpages. Seven 16-bit registers, 14-bit SELA/SELB/SELD/OPR word, source 000 external input and destination 000 no write, two pre-edge source values and shared ALU result. OPR implements the textbook example subset (MOV, INC, ADD, SUB, DEC, AND, OR, XOR, NOT, SHR, SHL); not a complete ISA. 64-word ascending register stack, 6-bit SP modulo 64, explicit FULL/EMPTY, PUSH increments before writing, POP reads before decrementing, retained physical words and distinct occupancy. Invalid/overflow/underflow operations leave state unchanged. Bilingual controls, actual hex tables and state transitions. This is not the chapter 5 CPU. Select source registers or external input, operation and destination; Execute edge commits one result. For the stack, enter a hexadecimal DR word and PUSH or POP. Physical data remains after POP but is not logically occupied. No electrical timing. Switching stack type resets the selected stack; the memory stack is a separate bounded teaching model.

## Engineering priorities (not release blockers)

P1: finish academic syntax acceptance and Basic Computer timing oracle; then reusable original programs for every applicable lesson, typed multi-bit hierarchy and persistent save/reset/undo, expanded memory and I/O experiments. P2: full chapter 7/8 control-encoding examples, advanced arithmetic and pipeline, hierarchy and multiprocessor timing. P3: optional electrical timing/datasheet-specific devices and richer cross-lab composition. Do not force all textbook work into first Stable/Beta; keep only independently accepted scope. For each item require source edition/section, bilingual explanation, actual engine, original saved scenario, independent oracle, errors/boundaries, accessible UI, persistence, real Windows visual and exact CI. No arbitrary completion percentage until precise edition mapping and denominator are known.

## Interaction / visual benchmark

- Current Qt Widgets code: ui/theme.py has three palettes, shared tokens and optional simulated gradient glass; ui/glass.py draws radial backdrop plus result pulse; ui/motion.py handles native tab indicator and 145ms button feedback; ui/signal_motion.py maps actual model events to routes. This is original simulated glass, not Apple's platform-native material or Windows compositor blur.
- Apple materials/motion guidelines: reserve translucent controls for navigation/action layers, maintain readable content, honor reduced motion/transparency; mouse feedback should be subtler than touch. Qt animation framework and QWidget update/mouse tracking support local native paint, not a separate render engine. Logisim-evolution's reusable subcircuits/live nets and Digital's measurement graphs/test vectors motivate practical usability (design benchmarking only, no code/assets copied).
- Stage A: reusable cursor-following specular rim on native buttons, immediate plain/reduced-motion/disabled/hidden fallback; no idle loop, layout shift or text opacity. Implemented in this PR; real Qt test and screenshot review pending.
- Stage B: hover/press spring-like retargeting, stable cursor anchors, keyboard-equivalent static focus, responsive navigation rail and floating inspector transitions; test fast pointer reversal, high DPI, RTL, focus and hit targets. Add drag ghost only for actual component drag, snap/connection feedback, pan/zoom minimap with real coordinate transforms, undo/redo.
- Stage C: measured selective Qt Quick or native compositor experiment on one replaceable surface only if it beats current Qt Widgets; keep offline and software-render fallback. No wholesale rewrite, no decorative CPU movement that changes or fabricates simulation data.
- Acceptance target: 100/150/200% scaling, 1024x768 and 1360x900+, both locales and all three themes, glass on/off, motion on/off, keyboard-only use, actual capture; native Windows frame-time measurements (target p95 under 16.7 ms on agreed reference device, not measured), no persistent animation while idle, no new UI/network dependency. Compare text contrast and focus in actual rendered states, not just tokens.

## Chapter 9 structural hazard and branch prediction
Optional shared instruction/data port blocks IF when MEM performs LD/ST; RAW holds take priority and are counted separately, and recovery redirect is queued for the next cycle. Branch prediction supports static not-taken (default), static taken and per-PC 2-bit saturating counters initialized weakly not-taken. Fetch records predicted next PC; EX compares actual next PC and flushes younger slots only on mismatch; direction and next-address mismatch are distinguished (same target as fall-through does not require a flush). Actual register/memory execution remains the same pipeline. Bilingual controls and timeline counters, independent sequential oracle across 36 configurations, loop learning, port conflict and UI tests authored. This is an ideal single-port timing abstraction, not a unified mutable instruction/data address space or cache. No variable memory latency yet.

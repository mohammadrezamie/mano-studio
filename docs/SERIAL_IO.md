# Serial I/O — ideal bit-slot laboratory


## Serial framing and receive buffering — Chapter 11
Implemented ideal aligned serial bit slots: 5–8 data bits LSB first, none/even/odd parity, one/two stop bits, deterministic single-bit corruption, real receiver shift accumulation, start/parity/stop error flags, and valid-frame insertion into the existing CircularFIFO (four entries). Bad frames are discarded; a valid frame received when full is dropped with overrun. Completion notifies the existing IRQ3 latch even for errors/overrun (coalesces while pending). Bilingual I/O subpage with code-drawn TX/RX waveform, per-slot trace, manual step, explicit paced playback/pause and immediate completion, queue contents. Playback stops when hidden; no physical timing claim. Config/reset clears the demonstration including queue. 38 learning routes across all 13 chapters. Tests authored for 24 legal configurations/2880 payload cases, corruption, overrun, IRQ, invalid inputs and GUI. Latest verified canvas dac6bea both runs green; later CI pending at inspection. No real UART sampling, electrical serial, baud recovery, CPU integration, translator, release or installer changes.

Frame: START=0, D0 through Dn−1, optional parity, STOP=1 repeated one/two times. Even parity bit is sum(data) mod 2; odd parity is its complement. A receiver without parity cannot detect a single data-bit flip. Start/stop checks assume the frame is already aligned, not start-edge detection. Each step sends one slot; Play uses a UI timer only, not baud. FIFO read is explicit and independent of IRQ acknowledgement. No error correction or automatic retry.

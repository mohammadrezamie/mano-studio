# Desktop UX specification
Status: design, not implemented. Priority P0 for three input modes, persistence and helpful errors. Use PySide6/Qt 6 Widgets, QSS design tokens, SVG icons, QSyntaxHighlighter, QSettings, Qt Linguist or centralized translation catalog. Keep Python 3.11/3.12 baseline for packaging; pin tested dependencies for releases, update via reviewed PRs and CI, avoid a second runtime or webview unless justified.
## Three interchangeable input modes
- Expert editor: UTF-8, LTR code in both UI languages; line numbers, highlighting, autocomplete, Ctrl+Space, undo/redo, file open/save, source-to-output mapping, F5 Translate. Accept ASCII alternatives <-, =, & and ~.
- Symbol pad: dockable calculator-style keypad inserting at cursor; register keys AC E PC AR DR IR TR INPR OUTR IEN FGI FGO S, memory M[ ], ←, =, +, ∧, ¬, [, ], (, ), :, comma, IF, THEN, hexadecimal 0–9/A–F, space, backspace, Enter/newline, cursor movement, undo, translate. Buttons must not steal editor target; support selection replacement. No physical keyboard required, including address entry. Accessible tooltips.
- Guided builder: grouped list of all 25 named instructions, bilingual operation names and explanation, direct/indirect selector for seven memory instructions, validated hex address field and clickable hex keypad, preview canonical RTL and generated ASM, add/replace/delete/reorder lines, all modes edit the same underlying text. Use instruction_catalog.build_rtl then translate(); never duplicate parser or silently change program. Preserve unknown manual lines instead of dropping them.
## Visual language
Original dark graphite/blue-teal theme with clear typography, rounded restrained components, split RTL/ASM editors, diagnostics bottom, instruction/help panel right, command/search palette Ctrl+Shift+P later. Light theme, Dark theme, Night theme (warm muted amber, low glare; not just dark), follow system optional, high contrast later. Persist theme, language, input mode and geometry in QSettings; load before splash. Persian full RTL UI, editor/addresses LTR. Fonts system fallback; bundle only suitably licensed fonts with notices. No mandatory animations.
## Splash and help
Show original logo, version, short bilingual acknowledgment of instructor Siavash Eshaghi (verify public attribution first), actual initialization stages, no unnecessary delay. Error guide keyed by stable diagnostic codes with bilingual summary, cause, repair, valid example, jump to source. ADDRESS_RANGE: 000–FFF, example AC ← M[FFF]; UNSUPPORTED_RTL: distinguish unsupported microoperation and syntax ambiguity; example AC ← M[100]. No export on error; mark stale output. Do not invent a precise cause when parser only knows syntax failed.
## Future additions

No user data collection. Local offline first; network update checks opt-in and official releases only.

## Mano Glass (user-approved direction)
Liquid Glass-inspired original portable Qt design: layered colored radial glows, translucent gradient controls, luminous rims, floating bars and opaque high-contrast code surfaces. All three themes inherit the glass style. Current implementation uses QPainter + QSS, not native Apple Liquid Glass, actual optical refraction, or OS desktop blur. Future work: restrained hover/transition animation, optional native Windows backdrop with graceful fallback, reduced-motion preference, visual review in all six language/theme combinations.
## Mano Live Lab
Initial interactive addition demonstration (LDA, ADD, STA, HLT), computed values from a separate pure Python demo CPU, animated conceptual bus direction, Play/Pause/Step/Reset, saved animation preference. It does not execute arbitrary editor programs or model microoperation timing. Future full simulator should emit structured events for fetch/decode/execute, register and memory changes, ALU operations and I/O; visualize real event data rather than fake animation. Add speed control, breakpoints, step back with snapshots, accessible nonanimated mode and plain-language Persian/English descriptions. Keep translator and simulator independent. No artificial loading delays.

## Primary translator usability
Keep RTL editor the default screen. A local instruction reference supports search across 25 mnemonics, descriptions and RTL, address and indirect options, verified preview through translate(), and insertion at the editor cursor's line boundary. Ctrl+Space opens the reference. Optional circuit/CPU labs remain grouped under Labs. No release activity until requested.

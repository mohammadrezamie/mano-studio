## Synchronous control state checkpoint
Replaced immediate boundary interrupt approximation with SC (4-bit timing counter), I (IR bit 15 at T2), and latched R. On each T3–T6 normal edge, pre-edge IEN and FGI/FGO determine R set; ION does not request on its own edge, IOF/INP can latch an already enabled request before clearing their flag. R selects next interrupt cycle; RT2 clears R/IEN/SC. SC increments after non-final groups and clears at completion. Existing reversible snapshots include all three fields. Breakpoints do not pause on a PC whose next cycle is interrupt service. Cycle view shows actual SC/I/R and RT timing labels. Reference https://open-book-project.github.io/courses/csa_course/register-reference-io-and-interrupts.html . External I/O remains restricted to instruction boundaries for deterministic replay; combined instruction bits, electrical delay and asynchronous input remain unmodeled. Tests revised for intentional interrupt latency change and new edge semantics; exact-head CI pending. No academic translator, installer or release changes.

## Navigation contract
`learning_catalog.py` contains chapter metadata, stable tool IDs, routes and original bilingual exercises. `ui/learning_center.py` owns search and explicit practice marks. `Workspace.launch_learning_tool` delegates to `ProgramLab.select_tool` or `LogicLab.select_tool`; neither catalog nor learning center calculates simulation results. The RTL editor remains default. The local progress key is `learning/practiced` (JSON list of stable IDs); unknown IDs are ignored. Opening a tool never changes practice progress or editor content. Search matches both languages and common technical terms. Chapters are provisional third-edition sequence; no claim of full textbook coverage.
